Module 1 · Search volume · how it works

Start from their services. Let Google's data find the searches.

  1. Read their site. List each service they sell.
  2. Expand each service with Google's keyword ideas. Never use a hand-written list: most made-up keywords get 0 searches. Real · ads playbook
  3. Keep buyer searches. Remove jobs, DIY, "how to", free, and salary searches.
  4. Count each idea once. Google repeats one volume across close phrasings: four phrasings each showed 8,100. Real · ads playbook
  5. Use their area only. Take 12 months, and note the peak month.
  6. Add Google's top-of-page price range for each search.

Module 2 · Who advertises · how it works

Module 3 · Competitor ads · how it works

Pull every live ad. Score each one with one rubric.

  1. Pull every live ad of the lead and the top 3 competitors from Google's and Meta's ad libraries.
  2. Save each ad as it ran: a screenshot, its dates, and the link to its library page.
  3. Record each ad's format (text, image, or video) and its words.
  4. Count for each company: live ads, ads started in the past 90 days, and the age of the oldest live ad.
  5. Score each ad with the rubric: 1 point for each check. 0-2 is weak, 3 is fair, 4-5 is strong.

1 · Service and place

"Water heater repair in Sandy."

2 · A reason to choose them

Price, offer, guarantee, or speed. "$89 drain cleaning, today."

3 · Proof

Reviews, years, numbers. "4.9 stars from 1,200 reviews."

4 · The next step

Call, book, or get a quote.

5 · Fits the format

Real photos, not stock. A hook in the first 3 seconds of a video. All ad space used.

Reviews: module 7 reads their reviews. The "Proof" check uses the stars and counts it finds. Your words: "pulling reviews is going to be a big one"

Module 6 · Tracking · how it works

Read the setup. Never trigger it.

  1. Load their home page, ad page, and contact page as a normal visitor. Stop each tag before it records our visit.
  2. List each tag that tries to load: Google tag, Tag Manager, Google Ads, Analytics, Meta Pixel, Microsoft, and call tracking.
  3. Read their Tag Manager setup. It is public. It shows which tag fires on which action.
  4. Check the form. Does it go to a thank-you page, or show a message on the same page? Is it in a box from another site?
  5. Follow the ad link's redirects with a test click ID, with no tags running. Check that the click ID survives.
Never: send a form, click a call link, or place an order. Each one adds a false lead to their data.
